# Techmo ERP

Internal ERP for Techmo Software Solutions — quotations, sales, purchases,
customers, suppliers, inventory, ticketing, after-sale records, reports and
analytics, with fixed user-role access control.

Stack: Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 + Supabase
(Postgres, Auth, Storage, RLS). Deploys to Netlify (frontend) + Supabase
(backend).

**Status:** Phase 1 of 8 — foundation, auth, fixed roles, company settings.
See the chat thread where this was built for setup steps and the full phase
roadmap.
